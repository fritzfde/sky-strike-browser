SKY STRIKE v0.5.0

Arrow Down = nose up · Arrow Up = nose down · Arrow Left/Right = roll · A/D = rudder (nosewheel steering on the ground)
W/S = throttle 0–100% (holds) · hold Shift = afterburner (at 100%) · engine spools up in ~1.5 s
G = gear (+ flaps) · L = flaps · X = speed brake · B = wheel brakes · V = cockpit / chase view
Mouse / touchpad = free look (C = recenter) · Space / left click = guns · F = missile (hold target in box ~1 s)
Takeoff: B off, full throttle + Shift, Arrow Down at ~120–140 kt, gear up · Land: gear + flaps, ~140 kt, under 1000 ft/min sink, wings level on the runway, then B + X
Stop on an airfield to repair and rearm · P / Esc = pause · M = mute

Click / tap to start
